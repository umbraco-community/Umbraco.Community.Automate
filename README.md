# Umbraco.Community.Automate

Monorepo for community-created [Umbraco Automate](https://github.com/umbraco/Umbraco.Automate) packages — connections, triggers, and actions for automating Umbraco.

## Packages

| Package | Description |
|---|---|
| [Umbraco.Community.Automate.DevTo](Packages/DevTo/Umbraco.Community.Automate.DevTo/README.md) | DEV Community (dev.to) connection and action — cross-post Umbraco content to DEV, converting Markdown, Rich Text, Block List and Block Grid to Markdown with a canonical URL back to your site |
| [Umbraco.Community.Automate.GoogleSheets](Packages/GoogleSheets/Umbraco.Community.Automate.GoogleSheets/README.md) | Google Sheets connection and actions (append/find/update/delete/upsert rows, read/clear ranges, create spreadsheets and tabs) |
| [Umbraco.Community.Automate.Mastodon](Packages/Mastodon/Umbraco.Community.Automate.Mastodon/README.md) | Mastodon connection and action — post statuses to any Mastodon instance, with visibility, content warnings, and appended URLs |
